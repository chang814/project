# 自适应复习提升计划（仅计划，未改算法）

当前实现采用 1、3、7、14、30 天的固定间隔；出错后在约 4 个词后再次出现，同词每组最多追加两次。它能加深短期印象，但把跟练正确与主动回忆混在一起，也不能根据个人遗忘速度调整间隔。

## 一、先区分回忆和打字
- 跟练正确仅算熟悉度，不作为已经能独立回忆的充分证据。
- 默写、句中填词中无提示且一次正确，才作为主要记忆证据。
- 使用提示或揭示答案，按需要重学处理；不要把随后照着输入算一次成功回忆。
- 单个错键且立即自行纠正，与完全想不起来分开。速度只作辅助，按词长和个人基线校准，排除页面切走、暂停及中断时间。
- 后续实现时补记：首键等待、提示使用、最终结果、模式、有效输入时间、错误位置、间隔。旧记录不伪造这些缺失信息。

## 二、间隔调度先用成熟模型，再验证适配
以 FSRS 作为候选，实施前锁定经过验证的具体版本；先用默认参数，数据足够再考虑个人拟合。调度库本地打包运行，不需要模型 API，也不需要上传学习日志；个性化拟合不作为第一版的前置条件。先以约 90% 的目标回忆率作可调试验值，不能声称真实记忆率已经达到目标。每日复习由历史回忆证据、经过时间和目标回忆率决定，不再只按连对次数推进固定天数。

实现边界：日间排期与组内重试分开；学习展示模式不能无条件推动长期稳定性；同日反复练对不等同于跨日记住。已有 due、streak、lapses 和日志保留，新增状态另行存储，支持回退。

参考：[FSRS 模型说明](https://open-spaced-repetition.github.io/ts-fsrs/guide/model/)、[Anki 算法说明](https://faqs.ankiweb.net/what-spaced-repetition-algorithm.html)。

## 三、组内复现不做机械循环
建议起始规则：首次遗忘隔 3–5 个不同词重现，仍失败则隔 10–15 个词再试；不足的间隔延至下一组。每词每组最多额外两次，总额外练习量不超过原组词数约 30%。这些是待验证的队列参数，并非已证明的最优值。连续失败的词转入下一次学习，避免无限加长一组。

## 四、控制每日负担与选词
先处理真正到期词，再补薄弱词和新词；集合去重，避免同一单词因多个标签挤满一组。复习积压时降低新词比例。建议首轮以到期/薄弱复习约 70–80%、新词约 20–30% 作试验起点，并保留用户选组、词库顺序和每日练习时间的控制。不要用未经验证的六级逐义频次给权重。

## 五、分阶段验证
1. 用现有日志回放检查时间计算、重试上限、提示处理与旧数据兼容。离线回放只能检查逻辑与拟合，不能证明新算法的学习效果。
2. 先做不影响正式排期的影子计算，记录建议间隔，不改变用户练习。
3. 经用户同意后短期试用，比较隔日/隔周无提示回忆、每个保留词的练习时间、连续失败次数与实际复习量。
4. 根据实际结果调整，保留一键回退和数据导出。

建议实施顺序：先完善回忆证据与日志，再试组内队列规则，最后接入并验证长期排期。本次 UI 修复不实现或启用这些变化。
