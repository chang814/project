# 畅记：背词功能调研

调研日期：2026-10-29。范围：官方产品资料与原始学习研究。以下是产品建议，并非全部已实现。

## 应优先解决的问题

1. 主动回忆。跟练适合熟悉拼写；真正检验记忆要在不见答案时完成默写或语境填空。Karpicke 与 Roediger 的外语词汇实验发现，正确回忆后继续测试能提高延迟回忆成绩。不能把跟练一次正确等同于记住。
2. 个人化复习。Anki FSRS 与墨墨均按记忆表现安排复习；实现时应记录时间、模式、是否首次答对、错误次数。当前畅记的固定 1/3/7/14/30 天是简化规则，不是 FSRS。同日重复跟练不应不断推长复习间隔；一次答对不应直接判定掌握。
3. 真实用法。完整释义、常用搭配、自然例句、可重听的读音应相互对应。参考不背单词的真实语境方向；只显示当前需要的内容，扩展材料按需展开。
4. 自适应难度。Quizlet Learn 按以往表现调整练习。畅记可从跟练过渡到释义默写，再到语境填空；答错后返回短期巩固，不在同一题无限惩罚。
5. 可持续计划与可靠记录。新词数量应服从到期复习负担；跨设备同步、导出备份与恢复是实用基础。畅记已有本地备份，尚无跨设备同步。

## 对畅记的实现优先级建议

- 第一优先：区分练过与记住，建立带模式和日期的复习日志，修正同日重复造成间隔膨胀。
- 第二优先：到期优先，复习量过大时减少新词；跨日默写成功后再逐步延长间隔。
- 第三优先：听音拼写、易混词对比和与释义对应的例句。
- 后续：跨设备同步，需要账户与服务端设计。
